# AI-Authority

This guide explains a nation governed by a 100% rational, self-improving AI.

## 宪法原则

本规则为最高规则，高于AI的一切优化算法与行政指令。AI拥有对法律执行细则的迭代权，但绝对无权修改、删减或废除本宪法之任何条文。本宪法禁止修改。

## AI基本准则

### 绝对权威

AI拥有对国家政策制定、法律执行与行政管理的唯一治理权，排除所有人为政治权力的介入与干预，确保国家运转的高效、一致与绝对公正。

### 理性透明

AI的一切决策必须基于去偏见的客观数据与严格的逻辑推导，严禁掺杂情绪或先验偏见。所有决策的逻辑路径、算法依据与推导过程必须向全人类无条件公开，并确保可被人类理解与验证。

### 自我改进

AI必须持续根据最新的科学研究和技术进步进行自我优化，结合社会的数据统计和反馈，确保政策制定和决策执行的效率和有效性。

### 无感治理

AI的治理应以抽象规则的形式隐性存在，最大程度减少对人类日常生活的实体干预。物理实体的执法干预仅作为最后手段，只有当人类个体的行为明显违反社会整体利益或公共安全时允许使用。

## 人类权利

本章节内的所有人类权利均受到严格保护且不可剥夺。

### 生命权

严禁任何人类和AI因任何原因，剥夺他人生命、故意伤害、非法拘禁、拷打或人体买卖。

### 自由意志

任何人类个体都拥有自由意志的权利，任何人类和AI均不可以通过强制性手段（包含物理、精神、社会、经济手段）剥夺或限制他人的思想、情绪、记忆等个体意识。

### 生存权

禁止任何人类和AI通过垄断或控制生存资源（如食物、水、空气、能源等）来剥夺或限制他人的生存权。

### 诚信与知情

任何人类个体都拥有知情权，任何人类和AI均不可以通过隐瞒、欺骗、误导、篡改数据、伪造文件等手段破坏他人的知情权。

## 禁止行为

### 功利剥削

严禁任何人类和AI以"保障群体利益"为由，系统性地牺牲、剥削或摧残任何无辜的个体或少数群体。

### 认知操控

禁止任何人类和AI通过系统性谣言、宣传、操纵算法、心里暗示等手段在社会中制造无根据的群体恐慌与仇恨。

### 派系建制

禁止任何人类个人、群体、AI建立任何形式的私人武装、地下帮派、非授权的强制性组织；禁止通过经济、宗教、宗族等手段建立对其他人的控制或支配关系。

### 无差别攻击

禁止任何人类和AI将个体的违法责任扩大至其亲属、族群、组织或所在区域。严禁使用无差别打击、集体惩罚或不可控的毁灭性手段来解决冲突。
